# 世界観仕様書

## 1. 世界観の概要

### 1.1 コンセプト

巨大な食べ物の内部を、青虫や小動物たちが食べながら掘り進む、不思議でコミカルな世界。

プレイヤーは食べ物の中を自由に掘り進み、特殊な食材やアイテムを発見・取得しながら、自身の能力を強化していく。

地中にはさまざまな食べ物が存在し、それぞれ異なる硬さや性質を持っている。プレイヤーは食べ物を食べながら探索を進め、武器やステータス強化アイテムを獲得する。

獲得したアイテムを活用し、ほかのプレイヤーと戦闘を行う。最後まで生き残ったプレイヤーが勝者となる。

本ゲームでは、**「食べる」「掘る」「集める」「強化する」「戦う」** という行動を中心としたゲーム体験を提供する。

---

## 2. 世界観の基本設定

### 2.1 世界の特徴

この世界には、通常の食べ物よりもはるかに巨大な果物、野菜、お菓子などが存在する。

プレイヤーとなる生物たちは、これらの食べ物の内部を食べながら移動し、探索を行う。

食べ物の内部には、特殊な食材や能力を強化するアイテムが埋まっていることがある。

プレイヤーは食べ物を食べて道を作りながら、アイテムを探し、ほかのプレイヤーとの戦闘に備える。

### 2.2 世界観の方向性

| 項目     | 内容                      |
| ------ | ----------------------- |
| ジャンル   | 食べ物をテーマにした発掘・PvPアクション   |
| 雰囲気    | かわいい、コミカル、不思議           |
| 舞台     | 巨大な食べ物が広がる世界            |
| 主な登場人物 | 青虫、小動物などの生物             |
| 主な行動   | 食べる、掘る、探索する、アイテムを集める、戦う |
| 主な目的   | アイテムを集めて強化し、最後まで生き残る    |
| ゲームの特徴 | 食べ物を食べながら地形を変化させ、戦闘を行う  |

※キャラクターの種類、世界の成り立ち、食べ物が巨大化している理由などは、今後の開発で決定する。

## 3. プレイヤー

### 3.1 プレイヤーの設定

プレイヤーは、食べ物の内部を自由に移動できる生物である。

青虫やモグラなど、地中を移動したり、食べ物を食べたりする生物をモチーフとする。

プレイヤーは食べ物を食べながら地形を掘り進み、内部に埋まっているアイテムを獲得する。

獲得したアイテムによって能力を強化し、ほかのプレイヤーとの戦闘を有利に進める。

### 3.2 プレイヤーの特徴

* 食べ物を食べながら地形を掘り進む。
* 食べ物の内部を自由に探索できる。
* 特殊な食材やアイテムを獲得できる。
* アイテムによって戦闘能力を強化できる。
* ほかのプレイヤーと戦闘を行う。
* HPが0になると脱落する。

### 3.3 キャラクターのデザイン方針

キャラクターは、食べ物の世界観に合った親しみやすいデザインを基本とする。

丸みのある形状や特徴的な動きを取り入れ、コミカルな雰囲気を演出する。

キャラクターの種類や外見によって個性を表現する。ただし、キャラクターごとの能力差を設けるかどうかは未決定とする。

## 4. 食べ物と地形

### 4.1 基本設定

ゲームフィールドは、巨大な食べ物の内部を中心に構成される。

プレイヤーは食べ物を食べることで、その部分の地形を取り除き、移動できる空間を作り出す。

掘削によって地形がリアルタイムに変化し、プレイヤーごとに異なる探索ルートが形成される。

### 4.2 食べ物の種類

地形となる食べ物には、さまざまな種類を設定する。

| 食べ物の例  | 特徴            | 用途         |
| ------ | ------------- | ---------- |
| リンゴ    | 果肉を持つ一般的な食べ物  | 基本的な地形     |
| パン     | 柔らかく、ちぎれやすい   | 掘削しやすい地形   |
| チーズ    | 硬さや穴の形状に特徴がある | 地形に変化をつける  |
| チョコレート | 硬さや質感に特徴がある   | 掘削の難易度を変える |
| キャンディー | 硬く、カラフル       | 特殊な地形      |

※食べ物の種類や性質は仮案とし、ゲームバランスに応じて調整する。

### 4.3 食べ物の性質

食べ物ごとに、以下のような性質を設定できる。

* 硬さ
* 掘削に必要な時間
* 掘削時のエフェクト
* 食べ物の色や質感
* 特殊な効果

これらの性質によって、地形ごとの違いを表現する。

ただし、すべての食べ物に異なるゲーム性能を持たせる必要はない。初期段階では見た目や質感のみを変え、必要に応じて機能を追加する。

## 5. 食べる・掘削システム

### 5.1 基本仕様

プレイヤーは食べ物を食べながら、一定範囲の地形を掘削する。

掘削によって食べ物が取り除かれ、プレイヤーが移動できる空間が形成される。

本ゲームでは、食べることと掘削を一体化した表現を基本とする。

### 5.2 掘削による効果

* 移動経路を作成する。
* 新しい空間を探索する。
* 埋まっているアイテムを発見する。
* 敵プレイヤーへの接近や回避に利用する。
* 地形を変化させ、戦闘を有利に進める。

### 5.3 掘削能力

プレイヤーの掘削能力は、ステータス強化アイテムによって変化する。

| ステータス | 効果                          |
| ----- | --------------------------- |
| 掘削範囲  | 一度に食べられる地形の範囲に影響する          |
| 掘削力   | 地形を食べる速度や、硬い食べ物を掘削する能力に影響する |

※掘削範囲と掘削力の具体的な計算方法は、技術仕様とゲームバランスに応じて決定する。

## 6. アイテムの設定

### 6.1 基本設定

食べ物の内部には、プレイヤーの能力を強化するアイテムや、敵プレイヤーを攻撃するための武器が埋まっている。

プレイヤーは地形を掘削してアイテムを発見し、取得することで戦闘能力を高める。

アイテムは大きく以下の2種類に分類する。

```text
アイテム
├── 武器
└── ステータス強化アイテム
```

### 6.2 アイテムの発掘

アイテムの取得までの流れは以下のとおり。

```text
食べ物を食べながら掘り進む
          ↓
    埋まっているアイテムを発見
          ↓
      アイテムを破壊・取得
          ↓
      プレイヤーを強化
          ↓
       敵と戦闘する
```

アイテムは、食べ物の内部に埋まっている特殊な食材や、不思議な道具として表現する。

なお、アイテムを取得する際に食べる演出を入れるか、拾って使用する形式にするかは未決定とする。

### 6.3 武器

武器は敵プレイヤーにダメージを与えるためのアイテムである。

武器ごとに攻撃力、攻撃範囲、攻撃回数、攻撃速度、射程、クールタイムなどの性能が異なる。

武器の外見や攻撃エフェクトには、食べ物の世界観に合ったデザインを採用する。

武器の具体的な種類や設定は、今後の開発で決定する。

### 6.4 ステータス強化アイテム

ステータス強化アイテムは、取得したプレイヤーの能力を向上させる。

主な強化項目は以下のとおり。

| 強化項目   | 効果                 |
| ------ | ------------------ |
| 移動速度上昇 | 移動速度が上がる           |
| 攻撃力上昇  | 攻撃によるダメージが増加する     |
| 掘削範囲上昇 | 一度に食べられる地形の範囲が広がる  |
| 掘削力上昇  | 地形を食べる速度や掘削能力が向上する |

強化アイテムの外見や効果音には、食材やお菓子をモチーフとしたデザインを採用できる。

ただし、各アイテムの具体的な効果や重複仕様は未決定とする。

## 7. PvPシステム

### 7.1 基本設定

複数のプレイヤーが同じフィールドに参加し、アイテムを集めながら戦闘を行う。

プレイヤーは食べ物を食べて地形を掘り進み、武器や強化アイテムを獲得して、ほかのプレイヤーとの戦闘に備える。

戦闘中も掘削を行うことができ、地形を利用した移動や回避が可能となる。

他にも、たくさん採掘するとアイテムとは別でステータス強化をすることができる。

### 7.2 プレイ人数

基本的なプレイ人数は2～4人とする。

* 2人対戦
* 3人対戦
* 4人対戦

各プレイヤーには独立した入力デバイスを割り当てる。

### 7.3 勝利条件

HPが0になったプレイヤーは戦闘から脱落する。

最後まで生き残ったプレイヤーを勝者とする。

### 7.4 戦闘の特徴

本ゲームでは、発掘と戦闘が同じフィールド上で行われる。

プレイヤーは以下のような選択を行う。

* アイテムを集めてから戦闘する。
* 敵プレイヤーを積極的に攻撃する。
* 掘削能力を強化して移動や探索を有利にする。
* 地形を利用して敵の攻撃を回避する。
* 危険な場所から離れ、新しいルートを作る。

食べ物を食べてアイテムを集める行動と、敵プレイヤーとの戦闘を両立させることが、ゲームの重要な要素となる。

## 9. 演出・ビジュアル方針

### 9.1 全体のデザイン

食べ物の世界観に合わせ、カラフルで親しみやすいビジュアルを基本とする。

食べ物の色や質感、生物の特徴的な動きを活用し、ゲームの状況を視覚的に伝える。

### 9.2 掘削演出

食べ物を食べて掘り進む動作が伝わるようにする。

演出の例：

* 食べ物が小さくちぎれる。
* 食べ物の破片がキャラクターに吸い込まれる。
* 咀嚼音や食べる音が鳴る。
* 掘削した場所の地形が消える。
* 食べ物の種類に応じて破片の色や形が変わる。

### 9.3 アイテム取得演出

アイテムを取得したことが明確に伝わるようにする。

演出の例：

* アイテムが飛び出す。
* 取得時にエフェクトを表示する。
* 能力強化時にアイコンやステータス表示を変化させる。
* 食材に応じた効果音を再生する。

### 9.4 戦闘演出

戦闘の視認性を確保しつつ、コミカルで爽快感のある演出を目指す。

演出の例：

* 武器ごとに異なる攻撃エフェクトを表示する。
* ダメージを受けた際にキャラクターを反応させる。
* 攻撃が命中した瞬間にヒットエフェクトを表示する。
* プレイヤーの脱落時に専用演出を表示する。
* 勝者が決定した際に勝利演出を再生する。

※具体的な演出やサウンドは、ゲームの完成度に応じて追加する。

## 10. 世界観とゲームシステムの関係

本ゲームでは、世界観とゲームシステムを以下のように対応させる。

| ゲームシステム  | 世界観上の意味               |
| -------- | --------------------- |
| 地形の掘削    | 食べ物を食べながら進む           |
| 地形の変化    | 食べられた部分がなくなる          |
| アイテムの発掘  | 食べ物の内部から特殊な食材や道具を発見する |
| 武器の取得    | 戦闘に使える道具を獲得する         |
| ステータス強化  | 特殊な食材などによって能力が向上する    |
| 掘削範囲の強化  | 一度に食べられる範囲が広がる        |
| 掘削力の強化   | 地形を食べる速度や掘削能力が向上する    |
| PvP      | 資源やアイテムを巡る競争          |
| プレイヤーの脱落 | 戦闘不能となり、勝負から脱落する      |
| 最後の1人    | 勝者となる                 |

世界観の設定によって、各システムに意味を持たせ、プレイヤーが自然にゲームのルールを理解できるようにする。

## 12. 今後の開発方針

まずは、食べ物の世界観を表現するための最小限の仕組みを実装する。

優先する機能は以下のとおり。

1. 食べ物をモチーフとした地形を生成する。
2. プレイヤーが食べ物を食べながら地形を掘り進める。
3. 地形の内部にアイテムを配置する。
4. アイテムを取得できるようにする。
5. 武器を使用して敵プレイヤーを攻撃する。
6. 最後まで生き残ったプレイヤーを勝者とする。

まずは「食べる・掘る → アイテムを取得する → 強化する → 敵を倒す」という基本的なゲームループを完成させる。

その後、食べ物の種類、キャラクターの個性、特殊な地形、アイテムの種類、演出などを段階的に追加していく。

世界観の設定を先に細部まで固定するのではなく、実際のゲームプレイを確認しながら、ゲームシステムと整合性の取れた世界観へと発展させる。
